ARQUITECTURA

La complejidad vive detrás de límites.

App Shell gestiona identidad y contexto. Los módulos gestionan los flujos de negocio. Backend Core gestiona las reglas de dominio. La base de datos refuerza el aislamiento por tenant.

DECISIONES DE PRODUCTO

Construye solo lo que el usuario necesita.

La demo evita deliberadamente fingir que es un ERP. Muestra una superficie de producto pequeña donde las decisiones de arquitectura son visibles mediante interacciones reales.

Propietario

Puede cambiar de negocio, gestionar datos y acceder a reportes.

Las acciones exclusivas del gerente pueden ocultarse a otros roles.

Contexto del tenant

Cambiar de negocio modifica el alcance de los datos sin cambiar la identidad.

La interfaz no muestra datos entre tenants.
